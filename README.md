Peach Cobbler Recipe Collection is a curated visual guide to classic peach cobbler, white peach variations, peach crisp, peach pie, and seasonal bakes. The collection organizes dependable ideas by style so each peach cobbler recipe is easy to browse and use.

Each entry keeps the details worth repeating: clear ratios, practical timing, finished-texture cues, and simple serving ideas. Use the collection to compare a Georgia peach cobbler with a quick peach crisp or move from peach fruit basics to peach cake, peach jam, and peach salad.

## How To Use It

1. Start with the recipe routes and choose a fruit style, preparation time, or finished texture.
2. Open the local [catalog template](site/website/templates/index.html) to review the collection layout.
3. Use the [builder](site/website/build.py) when regenerating the local catalog.
4. Record measurements, yield, timing, and one finished visual for every new entry.

| Ready To Serve | Review Before Baking |
|---|---|
| ![Clear visual cue](toolkit/misc/check.png) | ![Common mistake marker](toolkit/misc/forbidden.png) |

For additions, keep the recipe name clear and the description to one sentence. Include ingredients, numbered instructions, expected results, serving notes, and a finished image.
